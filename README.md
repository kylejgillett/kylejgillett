## SounderPy

[**SounderPy**](https://github.com/kylejgillett/sounderpy) is an open-source Python package for retrieving, analyzing, and visualizing atmospheric sounding data, built for severe and winter weather analysis.

[Web app](https://sounderpy.app) · [Docs](https://sounderpy.app/docs/) · [JOSS paper](https://doi.org/10.21105/joss.08087) · `pip install sounderpy`
